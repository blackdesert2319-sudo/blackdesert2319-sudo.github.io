1. Nhập đề bài (theo cú pháp đơn giản)
Mỗi dòng là một đối tượng. Cú pháp hỗ trợ:
• POINT Tên x y z – tạo điểm
• LINE Tên Điểm1 Điểm2 – tạo đường qua 2 điểm
• PLANE Tên Điểm nx ny nz – mặt phẳng qua Điểm với vector pháp tuyến (normal vector).
Ví dụ:
POINT A 0 0 0
POINT B 2 1 3
LINE d A B
PLANE (P) A 0 1 0
